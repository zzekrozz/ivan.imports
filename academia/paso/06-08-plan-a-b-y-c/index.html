Plan A, B y C

Viajas para inspeccionar una opción principal, no para quedar obligado a comprarla.

8 minAutor · IvánRevisado · 2026-08-11Fuente · páginas 79, 80
explanation

Explicación sencilla

El Plan A es el candidato principal con cita y condiciones confirmadas. El Plan B es una unidad previamente estudiada y contactada. El Plan C puede ser regresar sin coche o ampliar la búsqueda dentro de un radio razonable, no comprar cualquier cosa para justificar el viaje.

La guía propone aproximadamente 100 km como radio práctico en su contexto, una referencia experiencial que debes adaptar a transportes, horarios y densidad de oferta. Todos los planes conservan presupuesto máximo y criterios mínimos.

example

Marcharte también es un plan

El coche A falla la inspección. B ya no está disponible. El Plan C es volver sin comprar porque ninguna unidad supera los mínimos, no improvisar una compra fuera del encargo.

error

Error específico

Llamar Plan B a cualquier anuncio cercano que no has analizado ni contactado antes del vuelo.

action

Construye tres salidas

Registra A y B con cita, distancia y dossier; define C con hora límite y condiciones para regresar sin coche.

Resultado: Tres planes operables que mantienen los mismos límites.

Comprobación práctica

  • A y B están analizados y contactados.
  • Distancias y horarios permiten ejecutar la alternativa.
  • C incluye regresar sin compra si no se cumplen mínimos.

¿Qué no debe cambiar entre Plan A y Plan B?

El presupuesto máximo, la documentación mínima y los criterios de inspección.
